# Access Auto Garage DevOps Project

This repository contains a simple Jekyll website used to demonstrate a DevOps pipeline.

## Purpose

The purpose of this project is to demonstrate:

- Continuous Integration (CI)
- Continuous Deployment (CD)
- GitHub Actions workflows
- Automation in software delivery
- DevOps principles

The website itself is intentionally simple. The focus of the project is on the pipeline, not the complexity of the application.

## Theme

The website is based on a car garage (Access Auto Garage), providing basic content such as services and posts.
